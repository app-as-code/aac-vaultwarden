# Icon source

Icons are downloaded from the dashboard-icons collection (repository `homarr-labs/dashboard-icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/vaultwarden.svg` | Default (dark logo for light backgrounds) |
| `icon-dark.svg` | `svg/vaultwarden-light.svg` | Light logo for dark backgrounds (`prefers-color-scheme: dark`) |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/vaultwarden.svg
- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/vaultwarden-light.svg
